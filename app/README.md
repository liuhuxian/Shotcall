# Shotcall · 导演工作台

本地只读的短剧审核工作台。跑在 `zcai`，只监听 `127.0.0.1`，通过 SSH 隧道在浏览器打开。

**它不写创作文件**：`剧本.md` / `分镜.md` / `视频提示词.md` / `视觉设定.md` 永远只读。
判定、批次签字、挑片结果写进独立的运行目录，可追溯、可改判、可失效提醒。

---

## 启动

```bash
cd ~/gen_v/Shotcall/workbench
python3 server.py --port 8790
```

然后在你的端口转发里加 **8790**，浏览器打开 `http://127.0.0.1:8790/`。

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `WORKBENCH_STATE` | `项目/制作运行/`（不可写时退到 `app/run/`） | 决策、任务、选择、运行记录 |
| `WORKBENCH_MEDIA` | `项目/剧集/EP002/制作成果/` | 候选素材扫描根 |

启动日志会打印实际使用的状态目录。沙箱内跑会退到 `app/run/` 并给一行 `[warn]`。

## 能做什么

| 环节 | 能力 |
|---|---|
| 审核一 · 场次 | 逐场读剧本、原著出处行号、引用资产；通过 / 需修改 / 待定，可带意见，落账 |
| 审核一 · 资产 | 人物（身份→造型→状态）、地点、道具逐项判定；标"全剧共享" |
| 审核二 · 分镜墙 | 90 格按场分组，按 未审/已判/需修改/无提示词/短镜 筛选 |
| 审核二 · 单镜 | 分镜字段、首帧提示词、H3 六段式、参考图、台词链、上下镜翻页、判定 |
| 视频生成 | 读真实批次单，签字（gate=3）；预检阻断/警告/耗时；构造任务；**批准并提交**（后台生成 + 进度 + 自动回片） |
| 出图 | 资产图缺口、分镜图 0/90、图片批次单签字 |
| 挑片 | 扫描真实候选；**浏览器内播放**（支持拖动）+ 缩略图；重做原因标签；采用/备选/重做 |
| 检查 | 机械检查 + 当前依据文件版本（哈希） |
| 修改单 | 一键下载 markdown：审核一/二/批次/挑片/版本清单 |
| 全剧 | 18 集切换（标题下方），18 行进度表 |

## 三条约定（已固化进代码）

1. **写入边界**：工作台只写运行目录，创作文件只读。
2. **追加式事件流**：改判不改历史，新记录带 `supersedes`。
3. **版本粒度到单元**：判定绑定四个文件的哈希；文件一变，旧判定自动标「文件已变更·需复核」。

## 模块

```
parse_project.py   只读解析 4 个创作文件 → 结构化数据
dataset.py         整理成界面数据 + 缩略图（约 1.8 秒）
preflight.py       提交前预检（缺提示词/缺参考图/帧数越界/耗时估算）
planner.py         提示词六段拼装 + ComfyUI API 图（R2V）
submit.py          命令行构造任务；--execute --yes 才真提交
runner.py          提交/轮询/下载/重试/熔断；--simulate 可用历史记录验证回片
store.py           决策与选择的追加式存储
server.py          HTTP 服务：/api/data /api/decision /api/selection /api/preflight
                   /api/plan /api/execute /api/export /media（Range）/thumb
build_ui.py        由 ui_src/template.html 生成 ui/index.html
ui/index.html      界面生成物（单文件，无构建链、无依赖）
ui_src/template.html  界面源码（要改界面改这里，然后跑 build_ui.py）
test_all.py        36 项回归测试，不需要 GPU
```

## 数据流

```
剧本/分镜/提示词/视觉设定（只读）
        ↓ 解析
     /api/data
        ↓ 判定
  decisions.jsonl ← 版本哈希
        ↓ 批次签字 + 预检 + 构造
  tasks.jsonl → runner.py → ComfyUI → 下载
        ↓
  制作成果/ → 挑片 → selections.jsonl
```
