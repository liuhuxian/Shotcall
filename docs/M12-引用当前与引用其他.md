# 资产详情：引用当前 / 引用其他

- 日期：2026-11-24
- 变更：取消「文生图 / 改图」模式按钮，改成两个参考图入口。
- 截图：`docs/M12-引用其他.png`

## 1 新交互

- **引用当前**：把当前绑定图作为 H3 Image 的 `image_1` 参考图。
- **引用其他**：打开参考图面板，可：
  - 从项目内已有图选择（07 资产/绑定/候选、制作运行/首帧候选、引用图），带缩略图；
  - 输入任意**项目内相对路径**并「用此路径」；
  - 从本机上传图片（复制到 `制作运行/引用图/`，不把原路径写进项目）。
- 选好参考图后，提示词仍可编辑，点「提交生成」。
- 生成/采用历史仍显示在同一详情里。

## 2 接口

```text
GET  /api/img/refs                 # 项目内可引用图片（最多 300）
POST /api/img/upload               # raw image body + X-Filename，落 制作运行/引用图
POST /api/img/generate             # mode=edit + ref=...（UI 固定走参考图）
```

- 上传校验 PNG/JPEG/WebP/GIF 魔数，≤25MB；文件名清洗。
- 若项目 `制作运行` 不可写，退回 `WORKBENCH_STATE/引用图`。

## 3 说明

- 取消模式后，UI 不再主动走纯文生图；两条入口都是“带参考图生成”。
- 参考图不自动采用；生成后仍需在候选里点「采用」。
- `test_all` 50/0/2；`test_image` 13/0。
