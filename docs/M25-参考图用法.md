# 首帧参考图用法写进提示词

- 日期：2026-11-24
- 截图：`docs/M25-参考图用法.png`

## 变更

- 首帧页在参考图下方显示「参考图用法」，按当前勾选顺序生成：
  - `<Picture 1> = C01-A：身份参考…`
  - `<Picture 2> = L01-A：空间参考…`
  - `<Picture 3> = L02-A：空间参考…`
- 生成时自动把该段追加进 `prompt`，再提交 `/api/firstframe/generate`；不需要手动复制。
- **服务端也强制追加**：`firstframe.with_ref_instructions` 在 `/api/firstframe/generate` 内执行；即使绕过 UI 直接调 API 也会补，UI 已带该段则不重复。
- 参考图角色：
  - C* → 身份（脸/发型/眼镜/体态），不复制白底/多视图版式；
  - L* → 空间（布局/门窗/课桌/光线方向），不复制空镜构图；
  - P* → 材质/磨损/状态/尺度；
  - 文字首帧状态优先，参考图不锁构图。
- 不选参考图时提示「按文字描述生成」。
