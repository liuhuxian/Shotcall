## 3 接口契约（Lead 集成用）

### 3.1 `approvals.py`

```python
append(project, kind, target, verdict, *, path=None, version=None,
       scope=None, notes=None, by="director") -> dict
latest(project) -> list[dict]
state(project, kind, target) -> dict   # {record, stale, shaNow, reason}
file_ok(project, rel) -> dict | None   # 有效 file pass 才返回 record
summary(project) -> dict
```

- `kind ∈ {file, scene, asset, shot, pick, batch}`；`verdict ∈ {pass, revise, hold, na}`。
- 文件类必须能拿到 SHA；文件改动/缺失 → `stale=True`。
- 追加写 `制作运行/approvals.jsonl`；`fcntl.flock`；`os.fsync`；不删除。

### 3.2 任务状态

```python
# sched.submit(kind, items) 的 item 新增：
#   on_cancel: callable(reason: str) -> None
# sched._run_one 对 runner 返回值 True/False 记账
# _done 只在 True；_failed 在 False/异常
# 依赖失败时对下游 item 调 on_cancel("dependency_failed")
```

```python
vjobs.mark_cancelled(ids, reason) -> int
vjobs._execute(...) -> bool   # 失败返回 False，并写 status=failed
```

- `_execute` 提交成功后写 `dispatched`，不写 `running`；`reconcile` 看到 ComfyUI running 才写 `running` + `queueState=running`；看到 pending 写 `queueState=waiting`。
- `vjobs._save` 用 `fcntl` 锁 + `os.replace` 原子写。

