- 日期：2026-11-24
- 目标：**导演台是唯一项目管理层**；Agent 只按提示词执行单个阶段、写文件；导演在导演台登记/确认；生图、改图、视频也从导演台发起。
- 依据：项目内 `.agents/skills/` 的 `ai-film-router` + `film-*` 技能；当前项目 00–09 目录。
- 状态：**已按 1A/2A/3A/4A/5A 实现**：流程页、场次/资产审核、出图/改图、首帧、多项目切换与 C 测试均已上线。

## 0 总原则

> 2026-11-24 15:45：流程页上线；16:00：出图/改图上线（T2I 与 Edit 各实测 1 张）；16:20：首帧页上线。测试 `test_flow.py` 10/0、`test_image.py` 12/0、`test_firstframe.py` 8/0、`test_projects.py` 7/0、`test_revision.py` 11/0，`test_all` 48/0/2。


1. 一次只执行一个阶段；Agent 不自动跨阶段。
2. 每个阶段只新增 `vNNN`，不覆盖旧版；版本由导演台/`artifact_guard.py next-version` 给出。
3. Agent 只写创作文件；**不手改 `artifact-state.json`，不自行 confirm**；导演在导演台点「登记 / 确认」。
4. 下游只能使用 `已确认-当前` 或 `外部提供-已确认` 的版本；草稿不能进入下游。
5. 生图/改图/视频生成只在导演台点「提交」；Agent 不调用生成接口。
6. 项目内已有成果先作为基线；流程页显示“已完成/可重跑/待补”，不要求从 01 重做。

## 3 导演台「流程」页设计

每个阶段一张卡：

```text
01 概念锚定    [已完成 v001] [可重跑]
输入：00-原始资料/…
技能：ai-film-router → film-synopsis
输出：01-概念锚定/synopsis-vNNN.md
[复制提示词] [登记成果] [确认]
```

- **复制提示词**：把上面的卡填好当前项目路径/版本/范围；Agent 直接执行。
- **登记成果**：导演台扫描该阶段最新 `vNNN`，调用项目内 `artifact_guard.py register-draft`，写 `artifact-state.json` + `artifact-registry.md`；不手改。
- **确认**：调用 `artifact_guard.py confirm`；只有确认版能进入下游。
- **状态**：未开始 / 草稿待确认 / 已确认-当前 / 历史已替代 / 缺文件；来自 artifact-state。
- **重跑**：用 `next-version` 取新 vNNN；旧版保留。
- **跳过**：03/06 可登记“已跳过/不适用”，不占版本号。
- **依赖**：05 依赖 04/02/03；07 依赖 05；08 依赖 05/07；09a 依赖 08/07；09b 依赖 09a；生成依赖 09b + 镜头确认。

## 4 登记与「纯导演台」的边界

- 现在 `artifact-state.json` 由项目 `artifact_guard.py` 维护；导演台不要手写。
- 导演台调用项目内脚本（`.agents/skills/*/ai-film-router/scripts/artifact_guard.py`）：
  - `register-draft --kind --scope --path --depends-on`
  - `confirm --kind --scope --path`
  - `next-version --directory --stem`
- 如果项目以后不再带 `artifact_guard.py`，导演台再内置等价 registry；**过渡期以项目脚本为准**，避免双写。
- 导演台的 `approvals.jsonl` 继续管场/镜/挑片等编辑决策；阶段文档的“已确认/当前版本”以 artifact-state 为准，两者不互相冒充。
