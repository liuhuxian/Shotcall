# 同族成果：先选版本，再确认

- 日期：2026-11-24
- 问题：09 视频提示词有两份不同版本（音色版 v010 / 全单镜版 v011，另有已确认的 v012），旧页面按“每条登记”各给一个「确认」按钮，容易误确认两份。
- 修复：成果清单/待确认页按**同族**（路径去掉 `-vNNN.md`）分组：
  - 同族只显示一行；下拉列出该族所有版本/变体（vNNN · kind · 状态）；
  - 先在下拉选一版，才出现该版的「确认选中 / 退回」；
  - 已确认版本显示确认时间，不再给确认按钮；
  - 09b 的 v010/v011/v012 现在是一个族：v012 已确认，v010/v011 仅作为候选，选中后才可确认其中一版。
- 截图：`docs/M10-版本选择.png`
- 说明：这是 UI 分组与选择；artifact-state 里各变体仍各有登记记录，不会因为分组被删除。需要真正“只保留一个当前变体”时，后续可加归档/变体合并动作。
