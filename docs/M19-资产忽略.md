# 资产忽略：忽略/取消忽略 + 隐藏已忽略

- 日期：2026-11-24
- 截图：`docs/M19-资产忽略.png`

## 变更

- 资产卡第一排标签右侧新增小链接：
  - 正常资产「忽略」→ 写入 `00-项目管理/工作台/project.json` 的 `trashedSlots`，`revision` 递增；
  - 已忽略资产「取消忽略」→ 从 `trashedSlots` 移除。
- 资产页新增「隐藏已忽略（N）」复选框，**默认勾选**；取消勾选可查看被忽略资产并恢复。
- 分组标题显示“显示 N · 共 M · 已绑定 · 已忽略”。
- 忽略只写 `project.json`，不删 `slots`、不删资产文件。

## 接口

```text
POST /api/asset/ignore  {"asset":"P01-A","ignored":true|false}
```

- `assetsdb.set_ignored` 写 `trashedSlots`；`parse_ignored` 继续作为资产索引来源。
- `test_assets_ignore.py` 4/0；`test_all` 51/0/2。
