# 资产卡：版本/审核标签 + 通过/待定/修改

- 日期：2026-11-24
- 截图：`docs/M13-资产审核标签.png`

## 变更

- 资产卡第一排：**版本/绑定状态标签 + 审核状态标签**放在一起（如 `v5` + `通过`；未审显示 `未审`）。
- 第二排按钮统一为：**通过 / 待定 / 修改**。
- 取消「需修改」按钮文案，统一为「修改」；**资产卡的「修改」不再写审核 verdict，而是直接打开资产详情改图**（和点击资产标题一致）。
- 需要标记资产需修改时，不再从卡片操作；直接进详情改图/重出。
- 页头说明改为“逐项通过 / 待定 / 修改”。

## 说明

- 审核状态来自 `approvals` 的本地审批，不是 artifact-state 的登记状态。
- 资产「修改」只打开详情；审批账本只由「通过 / 待定」写。
