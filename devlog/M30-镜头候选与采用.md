# 镜头候选墙 + 一镜一采用 + EDL/CSV

- 日期：2026-11-24
- 截图：`docs/M30-镜头候选.png`

## 已做

- 按 **SH** 聚合所有生成结果（跨单元/版本/seed），不再按文件/单元散看。
- 每镜：主播放器 + 候选缩略视频 + provenance（单元/seed/batch/prompt/参考图/时间）。
- 一镜一个结论：`采用 / 备选 / hold / 重做`，采用必须写结构化原因。
- 记录写 `制作运行/video-picks.jsonl`（按项目 state 目录），后写覆盖前结论。
- 导出 `CSV` / `EDL`（按镜起始时间累加，采用项写入文件路径）。
- API：`GET /api/pick/candidates`、`POST /api/pick/adopt`、`GET /api/pick/export`。
